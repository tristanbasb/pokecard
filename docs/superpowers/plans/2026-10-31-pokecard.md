# Pokécard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Application web locale, utilisable au téléphone, qui identifie une carte Pokémon sur photo avec Claude Sonnet 5.5, retrouve son prix Cardmarket via TCGdex et gère la collection (état, langue, variante, quantité).

**Architecture:** Un processus Node (Fastify) sert une API JSON et un front statique sans build. SQLite stocke la collection. Claude et TCGdex sont injectés dans les modules pour que les tests tournent sans réseau.

**Tech Stack:** Node.js 24 (ES modules), Fastify 5, `@fastify/static`, `@fastify/cookie`, `better-sqlite3`, `@anthropic-ai/sdk` 1.x, `zod` 4, `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-31-pokecard-design.md`

## Global Constraints

- Modèle de l'app: `claude-sonnet-5-5`, sans suffixe de date. Le modèle de la session de développement ne change pas ce choix.
- Jamais de prix issu de Claude. Jamais de clé API côté navigateur.
- Échelle d'états, valeurs exactes: `Mint`, `Near Mint`, `Excellent`, `Good`, `Light Played`, `Played`, `Poor`.
- Variantes: `normal`, `holo`, `reverse`, `autre`. Langues TCGdex: `fr`, `en`, `de`, `es`, `it`, `pt`, `ja`.
- Interface en français. Le prix est libellé «prix de référence», la valeur totale «valeur estimée».
- Tout texte venant de Claude ou de TCGdex s'affiche via `textContent`, jamais `innerHTML`.
- `data/` et `.env` sont ignorés par git.
- Le dossier n'est pas un dépôt git: le Task 1 lance `git init`. Commits en fin de chaque task, avec la ligne d'attribution demandée par la session.

## Review Focus

- Double tap sur «Ajouter»: la quantité n'augmente qu'une fois pour un même scan. Test au Task 3.
- Passage d'une ligne à un état déjà possédé: les deux lignes fusionnent, sans erreur 500. Test au Task 3.
- Numéros atypiques (`025`, `TG12`, `SV107`, `GG05`, `001/165`): ils retrouvent la bonne carte. Test au Task 5.
- TCGdex en panne pendant le rafraîchissement: les anciens prix restent, sans être remplacés par du vide. Test au Task 4.
- CSV ouvert dans Excel français: accents, séparateur, virgule décimale et cellules commençant par `=` restent corrects et sans risque. Test au Task 8.
